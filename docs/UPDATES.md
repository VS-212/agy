# Обновления и повторный патчинг

## Почему автоапдейты отключены

Автоапдейт заменил бы пропатченные бинари свежими **НЕпропатченными** — вернулся бы экран
eligibility. Поэтому:

| Компонент | Как отключено | Как проверить |
|---|---|---|
| **IDE 2.0** | `resources/app-update.yml` переименован в `.app-update.yml.bak` (приложение не знает URL манифеста) | `ls ~/apps/antigravity-ide/resources/ | grep app-update` |
| **CLI `agy`** | функция в `~/.bashrc` подменяет команду: `agy() { command agy --update-check=false "$@"; }` | `type agy` → видна функция |

> ⚠️ `app-update.yml` «восстанавливается» при переустановке IDE из свежего архива.
> После каждой переустановки запускай `bash scripts/50_postinstall.sh` — он сам переименует
> `app-update.yml` в `.bk`, добавит функцию `agy()` в `~/.bashrc` и проверит патч (идемпотентно).

## Новая версия Antigravity (IDE/CLI)

1. Скачай свежий официальный архив сам (бинар в репо не живёт).
2. Положи в `~/Downloads` или передай путь через `AGY_IDE_ARCHIVE`/`AGY_CLI_ARCHIVE`.
3. Повтори конвейер:
   ```bash
   bash scripts/10_sources.sh
   bash scripts/30_patch.sh     # распаковка + патч (без сети)
   bash scripts/40_install.sh   # установка
   bash scripts/50_postinstall.sh
   ```
4. После 40_install / 50_postinstall:
   - проверь патч (`status`);
   - вход — как обычно, одним аккаунтом.

> Если 30_patch.sh вернул `2/3/4` («сигнатура не найдена») — см. следующий раздел.

## Новая версия патчера

Патчер работает по байтовым сигнатурам конкретных версий бинарей. Вышла новая версия
Antigravity с изменённым кодом → патчер «не узнаёт» бинарь и откажется патчить (это
безопасное поведение, ничего не испортит). Тогда обнови **сам патчер**:

```bash
# 1) РУЧНОЙ выпуск патчера в интернет, чтобы он увидел новые версии (разовый контейнер)
bash scripts/90_check_updates.sh

# 2) Обновить запатентованную копию патчера
git -C sources/patcher pull

# 3) Пересобрать песочницу с новым кодом
bash scripts/20_build.sh

# 4) Заново пропатчить установленные цели
bash scripts/30_patch.sh
bash scripts/40_install.sh
```

После этого снова: отключить автоапдейт IDE, проверить `status`, войти одним аккаунтом.

## Руководство по повторному патчу без новых архивов

Если бинари остались теми же (например, после переустановки системы), а патч потерялся —
достаточно:

```bash
bash scripts/20_build.sh       # образ уже есть — быстро
bash scripts/30_patch.sh       # использует источники из sources/
bash scripts/40_install.sh
```

## Несколько правил

- **Не обновляй вслепую.** Сначала читай `90_check_updates.sh`, патч — последним шагом.
- После каждого обновления проверяй `status` контейнером и `agy --version`.
- `sources/patcher` — это клон чужого GPL-проекта; обновляй его по официальному репозиторию
  `AvenCores/open-antigravity-patcher`, а не из непроверенных источников.
- Установленная версия, с которой всё проверено: **IDE 2.8.1** + **CLI 1.1.13** (патч x86-64).
